## 未知后缀引用按内容嗅探渲染

自 v0.26.3 以来的唯一功能提交（`424be9e`）随版发布，完整链路：

- **后端** `_sniff_kind` magic bytes 嗅探矩阵（png/jpg/gif/bmp/webp 图；ID3/RIFF-WAVE/OggS/flac 音；ftyp / `\x1aE\xdf\xa3` / RIFF-AVI 视频；BOM + utf-8/gbk 试解码文本，NUL 判二进制）+ 新端点 `GET /api/file-kind`
- **前端** `probeUnknownAssets()` 扫描 `.asset-box[data-probe]` 占位框异步嗅探后**原位升级**四形态；探测结果缓存 `_assetKindCache` 重绘不闪占位
- **编码感知**：`openFilePreview` 改 arrayBuffer + `TextDecoder(encoding)`——gbk / utf-16 文本不乱码（`r.text()` 恒 utf-8 旧疾）；`/api/asset` 对未识别后缀读头修正 Content-Type（`.bin` 里的 mp4 浏览器直接播而非触发下载）
- 验证：`test/test_file_kind.py` 14 例嗅探矩阵 + 真实文件 e2e + 路径穿越拒绝全绿

功能事实在发布前已记录于 [home.md 快速事实 09-09 · 二](../home.md#快速事实增补2026-09-09--二--未知后缀引用按内容嗅探渲染四形态自动升级)，本版正式随包上线。
