# 社区资产

> 由外部贡献者通过 PR 提交的 workflow / 节点插件 / skill / MCP 配置。
> 每个条目一个子目录，内含实体文件 + `entry.yaml` 元数据。CI 自动校验格式，merge 后通过 GitHub raw 立即可用，下次发版随包进入可下载资产体系。

详细贡献方式见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
