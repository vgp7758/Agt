## 发布细节

- **缓存经济学三连（本批核心）**：前两版（0.22.3 per-provider 双参数 / 0.22.4 无引擎改动）埋下三处判据/持久化缺陷，本版集中修复——①触发线误用保留水位（304bc16，v0.22.3 文档写对、代码没对齐，用户从行为反推抓出）；②触发判据估算分子 fc=0 假想恒超线（95f9a00，已折叠 session 每轮毕业）；③fc 不持久化 + 未顶窗清零，restart 后历史段头部重排前缀全断（7893bd5，t506 12.7% 命中）。修复后三线各司其职（触发线 win / 保留线 win×ratio / 保命线 panic），restart 前缀预期 85%+ 命中。另：recent-file 100K 上限（2c71e9a）与本批同属「投影膨胀治理 + 缓存稳定」主题。
- **配置隔离两件套**：`config.config_file(name)` 统一四份配置（main/models/settings/mcp）本地优先 + 写侧跟随；设置页 scope 三按钮（显式写非生效份只落盘不热应用，防「写了看似没生效」）。多实例角色化配置隔离的地基，VideoGameTeam 工作室（导演/编剧等角色 repo 各持配置）直接受益。
- **可观测性四件**：LLM 成功日志从 debug 提到 info（对齐 /stats tooltip 数值口径）；user 消息语义标签（803b3a5，通知轮渲染紫色系统气泡带 source 图标，批首归属语义）；系统气泡 markdown 渲染（fdfc28a，纯前端，/context 表格真表格）；scene 匹配 startswith("react")（3ae7a76 顺手修）。
- **修复链**：cc7dfbc 补 `_LOG` 定义（wiki-updater 23:44 加的日志引用未定义符号 → 躺平 1 小时）；85a41fd MODELS mtime 惰性重载（手改 models.json 后运行中进程自动可见，无需 /reload models）；d69bd8e busy 实例专属页放行（running 目标不再弹回主视图，实时可见其 thinking/step）；其余前端小修（日志面板复选框持久化 / logPanel 竖屏 / traceBox 宽度 / 气泡最小宽）随批。
- **版本 bump**：edit 工具直接改 `src/__init__.py` 的 `__version__`（0.22.3 → 0.22.4 确立的发布流程，干净一次过）。
