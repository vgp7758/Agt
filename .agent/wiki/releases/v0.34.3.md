# v0.34.3 发布记录（2026-10-10）

## 发布通道

## 版本内容

**核心：svc/sched 端点第一行 NameError 修复（commit ad87fd3，src/server.py 7 处 + 3 处死赋值清理）**

- `… = _state.get("agent") or agent` 统一改 **`ag = _agent`**（模块全局单例）——旧写法两个错叠加：`_state` 从无 `"agent"` 键 + 裸名 `agent` 不是模块全局 → 端点**从出生就没跑通过第一行**，请求必 500
- 覆盖 7 端点：sched_upd / sched_add / sched_del + svc_log / svc_fav / svc_op + ws plan 推送
- **0.34.2 的 deadline 修复（a516ce7）被这行挡在门外、从未执行**——0.34.2 用户必须升 0.34.3（500 还在）。反转全过程见 [background-scheduler · 后记二](../features/background-scheduler.md)

**顺带：site-packages/src 运行时遗留目录隔离（无代码变更，本机环境处置）**

- 此前 pip 在线版运行时写进包目录的孤儿模块+数据，以 namespace package 劫持 `import src`——**10-09 editable 启动 `No module named 'config'` 的真凶**；隔离改名 `__stale_bak_20261010` 后 editable 真正接管。见 [ops · 真凶闭环](../guides/ops.md#后记真凶闭环site-packagessrc-运行时遗留目录劫持-import-src2026-10-10v0343-轮隔离)

**验证**：隔离新起实例全链实测——sched_add（ISO deadline）/ sched_upd / 垃圾 deadline 明确文案 / 无此任务 / sched_del 全 200 JSON，零 500。
