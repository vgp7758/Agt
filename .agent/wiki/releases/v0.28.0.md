## 压缩阶梯补全 + 投影模拟器（本版核心）

完整设计、压力循环新顺序、862 轮回放数据、新旧对照表与三个诚实发现见 [context-engine · 压缩阶梯三改 + 投影模拟器](../architecture/context-engine.md#压缩阶梯三改--投影模拟器先升档推老档按轮吃2026-09-14用户提案)——一句话版：

- **压力循环新顺序**：升档 → 推老档 → 按轮折叠，每级只在上一级不够时才动；首刀大刀语义不变（超深段过半），起点之后的碎刀被「按轮吃」取代
- **按轮精确吃**：折叠目标从「对齐 boundary 整档吞」改为「恰好吃到估算 ≤ 保留水位」——不多吃一轮、不产生碎刀（每刀都断前缀缓存）；**主要收益来源**（fc 784→713）
- **模拟器**：规则改动先回放再上线——`python tools/proj_simulator.py <session_dir> --rule new --every 50 --csv out.csv`（换 `--rule old` 复现对照）

## 更新方式

```bash
/restart                         # 本机（editable 安装）即生效，无需 pip
pip install -U agt-agent         # 其它实例（comfy / 8000 / 云端）→ 0.28.0
```

改动在 session.py（引擎层）。生效后已有长 session 无需任何迁移——新阶梯在**下次顶窗**时自然接管（呈现更细的档位分层）；想预演某 session 的形状，直接跑模拟器。
