## 每日闹钟：四种写法一张表

| 写法 | 行为 |
|---|---|
| `at='09:00'`（短格式） | **每日 9 点闹钟**（repeat 缺省 True） |
| `at='09:00', repeat=False` | 只响下一个 09:00 一次 |
| `at='2026-09-05T12:00:00'`（完整 ISO） | 单次到点（原行为不变，兼容） |
| ISO + `repeat=True` | 也可每日循环（取时刻部分做锚点） |

## 实现要点（src/background.py + background_tools.py）

- `Schedule` dataclass 重构：`kind`（`interval`|`at`）/ `spec`（秒数|触发时间戳）/ `message` / `action`（`{"tool":...,"args":...}` 到点执行拿动态消息）/ `repeat` / **`daily`（每日锚点 `HH:MM[:SS]`）** / `next_fire`
- `_DAILY_RE = ^\d{1,2}:\d{1,2}(:\d{1,2})?$` 判短格式 + 时/分范围校验（`25:00` 这类非法时刻报格式错误）；ISO 已过时报「时间已过」
- **`_next_daily_fire()` 同秒边界（本版最关键一行）**：触发后重算明天锚点，候选 `<= now` 即再 +1 天——**同一秒内触发也必推到明天，当天绝不二次触发**（死循环根治）；每日任务触发后保留，单次任务触发后删除
- 工具层（background_tools.py，现 84 行）：add_schedule docstring 同步契约，repeat 默认 None 语义分发透传
- background.py imports 补 `re` / `timedelta` / `Optional`
