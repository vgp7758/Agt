# v0.29.5 发布记录

> 发布：2026-09-19，PyPI `agt-agent` 0.29.5（`src/paths.py` VERSION 0.29.4 → 0.29.5）+ GitHub Release。**运行形态自我认知 + 两处真 bug 修复专题补丁版**（自 v0.29.4 以来 3 个实质提交）。

## 发布内容总览

| 类别 | 内容 | 位置 |
|---|---|---|
| 🧭 **运行形态自我认知** | `_func_runtime_env()` → `_runtime_form()`（用户提案：让 Agent 知道「当前启动了一个服务在 localhost:8000，外界通过它与自己交互」）——输出五维：交互形态（CLI/WebUI 服务地址端口）/ 容器与隧道公网入口 / 消息桥接 / 数据目录 / 外部事件注入指路；内容启动后恒定（缓存前缀友好） | src/agent_config.py |
| 🐞 **端口预检 SO_REUSEADDR** | 端口预检 socket 加 `SO_REUSEADDR`——刚重启（旧进程 TIME_WAIT）不再误判「已占用」→ 实例不掉线（CNB 容器实测：旧进程 kill 后 5s 内再起必报占用） | src/server.py |
| 🐞 **callback 的 AGT_HOME 修复** | `api_callback` 改走 `config.load_runtime_settings()`——AGT_HOME 非默认环境（CNB 容器）下 callback_token 读不到、所有外部回调被拒；commit 523f8ba，随本版正式发布 | src/server.py |

## 要点速记

- **运行形态自我认知**：详情见 [运行形态自我认知](../features/runtime-form.md)。**直接影响行为**——网页气泡场景渲染友好（markdown/文件引用控件）、终端场景纯文本紧凑；知道被 daemon 桥接才知道回复要走回执协议。内容启动后恒定，不破坏前缀缓存。
- **端口预检 SO_REUSEADDR**：uvicorn 自身默认开该选项——预检与真实监听语义自此一致；「预检说占用」但实际能监听的自相矛盾自此消失。排障对照见 [ops · /restart 端口预检](../guides/ops.md#restart-端口预检-soreuseaddrtime_wait-误判占用实例掉线根因2026-09-19随-v0295)。
- **callback AGT_HOME 修复**：同轮 `docs/external-injection.md` + runtime_env 指路一并交付（上一轮迭代，本版公开可装），见 [外部事件注入](../features/external-injection.md)。
