## 施工模式投影（本版核心）

**一句话**：存在**未全部完成的活动 plan** 时，主 Agent 投影自动切换施工视图——history 不再装配（施工期模型不看几百 K 的对话历史），背景全部由头部**施工牌**（plan design 全文，头部第二条 system）承载；计划全部完成或 exit_plan 后动态判定、自动恢复正常投影（无状态同步，`session._construction_mode()` 每次装配现算，判定源 `agent_config._RUNTIME_AGENT` 与 plan_content 同源）。

关键性质（全量机制见 [context-engine · 施工模式投影](../architecture/context-engine.md#施工模式投影2026-09-13)）：

- **缓存经济**：施工牌施工期恒定 → 前缀 byte-stable，每步只增量计 steps/tail——比拖着大历史跨步便宜得多
- **防双份**：`plan_content()` 施工期返回空（design 已前移施工牌）；`plan_steps()` 进度留区3（每步变的内容在未命中区零扰动）
- **子 Agent 隔离**：判定绑定 `_RUNTIME_AGENT.session is self`，主 Agent 施工不波及子 Agent 的 history
- **可观测**：/context 顶部 `⚙️ 施工模式（plan 未完成：history 未装配·施工牌 N 字）`；history 段统计 meta 标「跳过(施工模式)」
- **存档无感**：history 只是不投影，recall / agent_query_events / 存档照常

**顺带修复（同 commit `f375483`，施工验证实测抓到）**：rf 快照层行号化污染——`_collect_file_snapshots` 给非 md 文件存的是行号化文本，rf 渲染层再行号化一次 → 双前缀 `1| 1│`；且大文件 outline 对行号化文本 `ast.parse` 必失败（session.py 恒显示「结构提取失败: IndentationError」的根因）。修复：快照存原文，行号化归展示层（见[后记二](../architecture/context-engine.md#后记二快照层行号化污染rf-双前缀--outline-恒失败2026-09-13随施工模式实测抓到)）。

**验证**：16+3 场景测试全绿；本 repo 开发轮自身实战闭环（施工牌生效 → 施工跨轮 → exit_plan 自动恢复正常投影），且交付验证轮的投影即首个实战样本——施工牌 `p_c1848eb7` 头部可见、plan_content 区3 块同步消失（防双份实证）。

## 其余三项（此前迭代，本版打包发布）

- **施工期 recent-file 回内嵌（`4fb84bb`）**：施工模式下 rf 段不再装配，当轮写过的文件快照回内嵌形态（贴该次写调用 result content 尾部，不去重、不限量）——施工期模型看不到历史，内嵌是唯一能看到的通道。见 [context-engine · 施工期 recent-file](../architecture/context-engine.md#施工期-recent-file回内嵌形态2026-09-13用户裁定)。
- **steps=reasoning 段级旧写法废弃（`b60cce8`）**：段级声明会把 tail/recent_file/钩子旁注等无姿势选择器的内建段一并拖进思考链（t781_s2 投影实证）；姿势声明收敛为逐动作项 `mode:` 键。见 [context-engine · 后记](../architecture/context-engine.md#后记段级旧写法-stepsreasoning-废弃姿势收敛到逐动作项-pose2026-09commit-b60cce8t781_s2-投影实证)。
- **plan 完成态投影瘦身（`f8fb2b9`）**：全部步骤完成后 `plan_content()` 只注一行标题（约 74 字，保留可见性：知道有 plan 挂着、可 exit_plan 收尾），`plan_steps()` 完成态不注入；进行态不变。见 [agents-admin · 后补二](../features/agents-admin.md#后补二plan-funcs-完成态瘦身design-全文--一行标题2026-09-13commit-f8fb2b9用户裁定)。

## 更新方式

```bash
pip install -U agt-agent && /restart     # pip 用户
```

生效验证：给主 Agent 挂一个含未完成步的活动 plan → /context 顶部应出现 `⚙️ 施工模式` 标注且 history 段标跳过；全部步骤 completed 或 exit_plan 后恢复正常投影、施工牌消失。桌面版：本版仅 PyPI + Git 发布，需安装包可走 GitHub Actions 云构建流水线（见 [desktop-mode](../features/desktop-mode.md)）。
