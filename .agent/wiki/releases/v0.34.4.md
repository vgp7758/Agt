# v0.34.4 发布记录（2026-10-10）

## 发布通道

`python release.py patch -y`（发布提交 `77c5536`）：版本 0.34.3 → 0.34.4 → 构建 whl + tar.gz → PyPI ✅ → Git push（`5d3f3df..61255d0`，含 4 笔 wiki 维护 docs）。PyPI：<https://pypi.org/project/agt-agent/0.34.4/>

发布提交本身只含版本号两处（packaging/version_file.txt + src/paths.py `VERSION = "0.34.4"`——pip 侧 `__version__` 真源，`src/__init__.py` 反向导入保持一致）；四笔功能提交此前已逐笔落库，patch 一次打包带入。

## 版本内容

**主打：steps 分档模式（投影轮间分档的确定性阶梯）**——settings `"tiering_mode": "steps"` 显式开启，**默认空 = 现行算法完全不受影响**。三笔提交演进：

| commit | 内容 |
|---|---|
| `ed6ab2d` | steps 分档模式本体：档位边界由**步数守恒**唯一决定（五档 500/600/1200/2400/4800 可配，`tier_steps` 长度必须 5），与 token 估算无关；从零重算与逐轮增量完全一致（1500 轮随机步数对拍相等），读档缺失才重算兜底 |
| `08b4758` | 顶窗大动作改**三级级联**：① fc→sos 增量浓缩 → ② 工具折叠档→fc → ③ 档2/3/4→工具折叠档——每级下压一格、梯度保持；轮内保命阀只做 ②③ 零 LLM |
| `5d3f3df` | fc→sos **三段并行**：区间预计算一次并发发出（实测 0.46s vs 串行 1.2s）+ 失败前缀落账（sos 覆盖必须连续无洞）+ 每段自带实例级回退链确认 |

**同批：RAG 首启冻结修复（`ac753c0`）**——`USE_TORCH=1` 阻断 transformers 的 TF 连带 import（导入 20.5s→12.2s，tensorflow 完全不加载）+ 预热单飞 + 默认延迟 15s 启动。fresh 实例「服务就绪 → 页面加载压在 RAG 导入窗口 → 进程冻死数分钟不自愈」根治。

**验证**：steps 三笔各自隔离环境全绿（900/12/1500 轮场景 + 顶窗坍缩 + 渲染冒烟；三段并发 3 线程实测、失败前缀语义验证）；RAG 对照验证 playwright 秒开 + 63s 连续探测 14/14 全 200。

## 更新方式

| 实例形态 | 操作 |
|---|---|
| editable（如 9000/9013） | `/restart` 即生效 |
| pip 在线版（如 20048） | `pip install -U agt-agent`（≥ 0.34.4）→ 重启 |
| 开启 steps 模式 | settings 加 `"tiering_mode": "steps"`（可选 `tier_steps` / `tier1_flush_steps`），需 `/restart` |

⚠️ 阿里云/清华镜像同步通常滞后 10~30 分钟——拿到旧版加 `-i https://pypi.org/simple`。
