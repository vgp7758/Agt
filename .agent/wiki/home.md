## 快速事实（2026-08 状态）

- 版本 **0.19.2**；`pip install agt-agent`；CLI=`agt`，WebUI=`agt-web`
- 38 个 Python 模块 ~17000 行，零 LangChain 依赖
- 主 Agent id=`_main_`；子 Agent 声明在 `.agent/agents/*.md`（frontmatter DSL）
- 工作流：`.agent/workflows/*.xml|json`，13 类节点，XML 为推荐写作格式
- 工作流 meta 字段：name/description/hook/enabled/hidden/async/auto/coze_url（全链路读写；**hidden 默认 true——未写=不注册 wf_* 工具，显式 hidden="false" 才进工具箱 schema，commit a667da4**）
- 存档：`~/.agt/repos/<repo 目录名>/`（sessions/memories/plans/specs/images/rag；路径由 workspace hash 改为可读转写）
- LLM 调用流水：每 session `llm_calls.jsonl`（含 resp_model/scene/turn·step 轮步标记/usage 归一化）
- 前端气泡：系统自动触发默认折叠，用户指令默认展开，点击切换；聊天面板 user/answer 气泡 hover 浮现复制按钮（innerText 复制，clipboard→execCommand 降级，commit 3a7e9de）
- 运行时状态：POST `/api/status` 返回实例快照（18 顶层字段 + 3 嵌套数组），用于跨实例诊断
- **管理页回退链表单 + hidden 默认翻转（2026-08，commit a667da4，四件套）**：①/agents 每个编辑视图（含 `_main_`）新增回退链区——模型 chips 点选（与工具选择同款交互，点击顺序=链序）+ 策略下拉，留空=继承全局 settings；声明级 `fallback` 键三形态（逗号串/list/{chain,policy}）引擎侧 `_parse_agent_fallback` 早已在新建/复活/reuse 三路径消费（改链后 reuse 下一任务即生效），此前只能手写 yml。②编辑器钩子下拉移除——钩子挂载统一走 /agents 的 hooks 编辑，meta.hook 原值透传不丢。③hidden 默认翻转：未写 hidden=默认不注册为 wf_* 工具，显式 hidden="false"（编辑器取消勾选+保存）才进 schema——存量 22 XML 已全显式 true，行为零变化。④管理页钩子行布局修复（值输入框 flex 自适应，async/× 不再被全局 input width:100% 挤下一行）（详见 [agents-admin](features/agents-admin.md)、[multi-agent](architecture/multi-agent.md)、[workflow-hooks](architecture/workflow-hooks.md)、[editor-ux-improvements](features/editor-ux-improvements.md)）
- **real_tools 再外置 8 工具 + 节点目录动态聚合（2026-08，commit 17312eb）**：①纯函数批——length/to_uppercase/to_lowercase → str_tools；kv_cache_read/write → 新建 kv_tools（**`_KV_CACHE` 状态随外置件走**：进程级自写自读 dict，缓存键=namespace+内容 sha1，namespace 兼作版本号，重启清空=结果缓存语义）；diff_lines → 新建 diff_tools（Myers 三件套**算法副本**+随机重放 200/200 回归，框架 diff_files 保留原件，双份注释互指路）；cosine_sim/emb_probe 本体迁 `src/rag.py`、注册并入 rag_tools.py（embedder 单例共生）——**LIGHT_TOOLS 13→5，剩余全是框架状态型**（ReAct 原语三件套 `_WF_CTX` 注入 + dir_outline/concat_files `_resolve` 沙箱），外置扫描 43 工具全验证。②`_NODE_CATALOG` 动态聚合——各插件 `agt_node()` 声明 catalog 字段（`_CATALOG`：name/desc/xml），`node_plugins.catalog_entries()` 自举聚合，`real_tools._node_catalog()` = 核心 12 + 插件 13 = **25 种**；10 个已迁移节点条目搬进各自 .py（元信息跟实现走），AND/OR/timestamp 目录新写（此前进不了 list_workflow_nodes 的缺口补上），用户级 `.agent/nodes/` 目录声明同样生效——**以后写新节点插件，目录自动跟着进**。③wiki_auto_maintenance 模板措辞中性化（`user message:` 判官口吻裸转储 → 「本轮交互与文件改动（维护 wiki 的依据）」）。`/restart` 后生效（详见 [tool-externalization](features/tool-externalization.md)、[tool-externalization-criteria](architecture/tool-externalization-criteria.md)、[node-plugins](architecture/node-plugins.md)、[wiki-auto-maintenance](features/wiki-auto-maintenance.md)）
