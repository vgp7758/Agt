编辑子 Agent

基本信息

点工具 chip 快速增删；留空=继承全部（除管理工具）。
点模型 chip 快速增删回退链（声明级：该 Agent 的 llm 独立生效；留空=继承全局）。

SYSTEM 正文（persona）

保存时写回 assembly 首个 text: 项（v2.1 起存为独立 .md，每轮投影重读）。

上下文装配 assembly（顺序即装配顺序，只装列出的段）

段名：system=声明正文 / rules=AGENTS.md与规则 / history=分档历史 / user_message / steps=轮内步骤（可加模式：steps=reasoning 使 steps 后的段注入末条 assistant 的 reasoning_content 前缀，默认 reminder=包裹并入末条 content）/ tail=易变尾块 / hooks=钩子旁注。动作项：text=静态文本 / file=读文件 / dir=目录清单 / cmd=命令输出 / workflow=执行工作流 / tool=执行工具（每轮求值注入）。

钩子 hooks

位置：before_turn / after_tool / before_answer / turn_end。类型：workflow=工作流名 / cmd=命令 / emit=事件。async=后台执行不阻塞。
