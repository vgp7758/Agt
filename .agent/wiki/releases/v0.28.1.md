## 根因：为什么一直没暴露

`_type_to_schema`（`src/tools.py`）把 Python 类型注解转 JSON Schema 片段：白名单 str/int/float/bool/list/dict + `typing.Any` → 空 schema（编辑器不锁死类型）。`Optional[int]` 实为 `Union[int, None]`，不在白名单 → 工具注册扫 schema 时直接抛 TypeError。

**开发机没炸、PyPI 包炸**的组合拳：

- 本机 editable 安装，进程不重启就不重扫 schema——旧进程内存里还是老代码，问题静默
- PyPI 包装进**全新 Python 3.10 环境**（SCNet 容器 `pip install agt-agent` → `agt-web` 首启）第一次扫工具就踩中

发现现场：[SCNet · 无卡模式镜像构建](../guides/scnet.md#notebook-无卡模式镜像构建015-实例-agt-组网--环境持久性实测2026-09-14)——无卡模式容器里装 agt 组网时炸出，热修后容器内验证（重启后仍在），当晚发版。

## 修复（src/tools.py 两处）

- `_type_to_schema` 增 `get_origin(ptype) is Union` 分支：args 剥掉 NoneType——剩单参数 → 退化为其 schema（`Optional[int]` ≡ `int`）；剩多参数 → 仍报不支持（真 Union 未支持，显式炸比静默丢类型好）
- import 补 `from typing import Union as _typing_Union`
- docstring 记录坑位与本次事故（Optional[X] → X 的 schema）
