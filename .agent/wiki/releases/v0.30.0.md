## 发布插曲：git push 走 22 端口（~/.ssh/config 的 443 重定向失效）

首推失败 `ssh: connect to host ssh.github.com port 443: Network is unreachable`——`~/.ssh/config` 历史重定向（22 被墙时代绕行 443），当晚实测反转（443 超时、22 可达）。repo 级兜底：`git config core.sshCommand "ssh -o HostName=github.com -p 22 -o ConnectTimeout=20"` → main + tag 推送成功；还原用 `git config --unset core.sshCommand`。详见 [ops · git push SSH 路由](../guides/ops.md#git-push-ssh-路由sshconfig-的-443-重定向失效时-repo-级-coresshcommand-兜底2026-09-23v0300-发布轮)。
