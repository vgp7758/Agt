## hooks async 键静默丢弃修复（本版核心）

**用户报告**：/agents#edit 编辑时，钩子勾上 async 复选框后 yml 形态是

```yaml
turn_end:
- workflow: recap_gen
  async: true
```

「但实际读取后运行时是同步的，结果会被注入并阻止轮结束」。

**根因**：`src/multiagent.py` `_parse_hooks` 解析 dict 项时只消费 kind 键（`workflow`/`cmd`/`emit`/`value` → 字符串解析），其余兄弟键静默丢弃——`async: true` 从未成为 item 标志位，运行时读不到 → 按同步跑。字符串形态（`'workflow: x | async'` 尾随标志）一直正常，dict 形态（管理页保存的唯一落盘形态）全灭。

**修复（cb7e7d1）**：kind 键解析后，遍历 dict 其余键，真值兄弟键提升为标志位 `item[str(k).strip().lower()] = True`（排除 workflow/cmd/emit/kind/value 六结构键）。dict 项两类来源都修复：管理页保存的 `{workflow: x, async: true}` + agent_prompt 注入默认的 `{kind: workflow, value: x, async: true}`。

**边界**：`async: false` 显式 false 与不写同义（falsy 不设标志）——关 async 走编辑器取消勾选。

完整机制与关联页见 [workflow-hooks · dict 项 async 修复](../architecture/workflow-hooks.md#钩子声明-dict-项的-async-键静默丢弃修复2026-09-12commit-cb7e7d1用户实测抓到随-v0267-发布)。
