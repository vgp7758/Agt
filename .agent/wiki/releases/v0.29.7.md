## 要点速记

- **活跃窗口双口径分治**：SYSTEM 注入（`get_team_profiles` func 项 → `format_team(active_window=True)` 默认）走「running/idle 恒显 ∪ 近 30 轮交互过」窗口；三个显式查询端（`list_team` 工具 / `/team` 命令 / WebUI 团队看板 `team_list` 推送）显式 `active_window=False` 保持全量——投影瘦身不牺牲查询能力。发布轮实证：30 条 registry 条目 → SYSTEM 只列 main 一行 + 尾注「另有 29 个实例近 30 轮无交互未列出」
- **recall 关键语义**：折叠只发生在投影渲染侧，user/answer 原文始终留在 turns——「被折叠为结构摘要的轮」命中时照样整段原文召回（详见 [recall-tools](../features/recall-tools.md)）
- **宽度修教训**：flex item 的 automatic min-content 是隐形撑宽器（宽 diff/表格能把 `.turn` 撑到 1600px+ 带整页横向溢出）——`min-width:0` 是标准解法（详见 [trace-fold](../features/trace-fold.md)）
- **push 状态**：发布时 GitHub SSH 22/443 间歇不通，本地 commit 挂每 10 分钟自动重试——不阻塞 PyPI 发布（v0.29.6 确立「PyPI 一发即为版本真源」，发布流程不依赖 GitHub Release 兑现）
