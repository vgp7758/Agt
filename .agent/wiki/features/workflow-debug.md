# 工作流调试页 · 节点输出白框（画布内联 + 可折叠）

> src/static/workflow_debug.html（单文件纯前端）。2026-08-21 新，commit 6c804a2。

## 职责

调试页画布「播放」工作流后，每个**执行过的节点**下方自动挂一个白框（SVG `foreignObject`，白底黑字等宽字体），直接显示该节点的输出结果；白框顶部灰色头条可点击折叠/展开。调试时不需要切页面——编辑 → 播放 → 在画布上看每个节点实际产出，闭环就在眼前。

```
┌─ [节点卡] ──────────────┐
│  llm_call        🔧     │
│  ○ messages      raw ○  │
└─────────────────────────┘
┌─ ▾ 输出 · 4 字段 ───────┐  ← 灰色头条，点击折叠/展开（▸）
│ content: 分析完成，分档… │  ← 每字段一行，截断 240 字
│ tool_calls: [{"name":..│     最多 16 行 + 滚动
│ usage: {"prompt": 1254…│
│ finish_reason: tool_calls│
└─────────────────────────┘
```

## 实现

### nodeH 拆分：_baseH + 输出框高（核心）

节点高度一分为二：

| 函数 | 职责 |
|------|------|
| `_baseH(n)` | **基础高度**：`HDR_H + max(输入行数, 输出行数)×ROW_H + PAD`（type1 只数出边行、type2 只数入边行），再叠加类型特有高度——type15 文本框 `TEXTAREA_H`、type5 代码预览 +40、type8 选择器分支 `(分支数+1)*22+8`、type21/28 复合节点编辑按钮 +36、type32 聚合分组动态高度 |
| `nodeH(n)` | `_baseH` + 输出框高（`_dbgBoxH`）——**布局避让与连线计算用 nodeH**，白框自然被当作节点占地的一部分，不会与下方节点重叠 |

节点 body rect 高度固定为 `_baseH`（输出框在 body 之下单独渲染，不计入 body）。

### 白框渲染 `_renderDbgBox(g,n)`

- `dbgOut[n.id]`（nodeId → 输出值，播放执行时记录）不存在直接 return——只有执行过且有输出的节点才挂框
- **y 位置从 `bodyRect` 实际 `height` 属性读取**（`parseFloat`，兜底 `_baseH`）：type22/32 的 body 高度在校正阶段被改过，从 rect 读最准，白框始终紧贴 body 下缘（+2 间隙）
- 头条「▾ 输出 · N 字段」；点击调 `toggleDbgBox` 切换折叠（折叠后 ▸ 只剩头条）；**`dbgCollapsed`（Set）跨 renderAll 保持**，重画不丢状态
- 内容区每字段一行（`key: value`，截 240 字），最多 16 行，超出滚动
- 样式**全内联**——不依赖外部 css，不污染调试页其它元素

### 端口锚点不受影响

body/error 端口位置一律用 `_baseH`（**不含**输出框高度）：error 端口在 `(n.w, _baseH-6)`，`portPos` 的 error 分支同理——连线锚点稳定，不随白框出现/折叠/增高而跳动。

### 只读模式适配

`toggleDbgBox` **不入只读拦截清单**——折叠白框是调试页允许的交互（查看行为，不算编辑）。

### 顺手修掉的两个老问题（_baseH 拆分时暴露）

- **type32 `n.h` 二次覆盖**：聚合节点渲染中把 `n.h` 直接赋值，会把 nodeH（含输出框高）的计算覆盖掉 → 删；body 高度改为 `bodyRect.setAttribute('height', _baseH(n))`（分组动态高度已在 `_baseH` 内）
- **重复 `const bodyRect` 声明**：JS SyntaxError 风险 → 合并
