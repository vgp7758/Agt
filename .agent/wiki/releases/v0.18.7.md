## 编辑器 UX 四件套（核心）

prompt 编辑不再必须开右侧属性面板——LLM 节点在画布上直接给 120px textarea（oninput 直改数据不重绘，防重绘销毁丢焦点）；批处理开关上移到输入字段之前（开关决定字段的「源」选项与输出结构，先看开关再编字段）；批处理开启时输出字段区自动管理（all_outputs / filtered_outputs / nth_output 三输出，item 结构从节点原输出 schema 自动推断），关闭还原。详见 [工作流编辑器 UX 改进](../features/editor-ux-improvements.md)。

## 修复

- **聚合节点选值语义**（commit 5117f41）：aggregator(32) 分组变量旧版「blockID 执行过」即取值——var1 执行了但字段解析为 None 时整组直接 null，var2 有值也被忽略（用户报告「var1=null 直接分组返回 null」）。现按声明顺序取第一个「执行过且值非空」；空列表/空 dict 是合法值不跳过。九场景验证。
- **/stats 拖拽 tooltip**：吸附竖线锁定数据点后，tooltip 同步**锁定到该数据点**、y 跟随曲线起伏——横扫多条折线时 tooltip 始终贴着当前数据点，读数与曲线视觉位置一致。
