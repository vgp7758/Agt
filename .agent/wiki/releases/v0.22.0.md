**生效方式**：工作流每轮重扫（hook 类不用重启）；引擎/后端类 `/restart`；编辑器类 Ctrl+F5。

## 发布细节

- **hook_write 迁移**：recap_gen.xml 改造为 `start(+hook_ctx) → llm → code 组装 payload → plugin hook_write → end`；`_async_hook` 的 recap 分支（meta.recap/name 兜底 17 行）删除；`hook_write` 闭包绑定 agent 主/子双注册（子 Agent 重绑自身版本）。多 turn_end 钩子共存时谁调 hook_write 谁负责，后写覆盖先写。
- **钩子根属性恢复**：5 个工作流补根属性（before_turn_retrieval/wiki_auto_query 补 `hook="before_turn"`、py_auto_diag/cs_auto_diag 补 `hook="after_tool"`、recap_gen 补 `hook="turn_end" async="true" recap="true"`）+ server PUT 保底合并（UI 不管理的字段不被 UI 保存抹掉）。
- **comfy repo 侧更新路径**：工具脚本/节点插件零操作（不落播种副本，随包扫描，升级即新版）；工作流 XML / agent 声明 yml 需 `pip install -U agt-agent` 后跑一次 `/update-assets apply`（三方 hash 判定，手改过的工作流跳过保护，`--force` 才覆盖）。main.yml 不在 manifest（属用户配置不播种）。
