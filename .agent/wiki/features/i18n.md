# WebUI 界面国际化（i18n） · 中英双向字典引擎（2026-10-04，用户提案，commit 9a982e7）

## 职责

WebUI（src/static/index.html）全界面中英双语：静态文案运行时替换、动态渲染区自动跟随、语言偏好浏览器级记忆。第一版只覆盖 WebUI；字典渐进补齐，**缺翻译自动 fallback 原文**（双语混排过渡期页面不残缺）。

## 双向字典设计（用户提案的核心巧思）

```
字典一份：src/static/i18n/dict.json   { "中文原文": "English text" }
引擎加载时建双索引：zh2en + en2zh（同一文件两个方向都能查）
  en 模式：界面里的中文原文 → 替换英文
  zh 模式：界面里的英文原文 → 替换回中文（Agent 双语环境下写代码，
           UI 文案写哪侧都能被归一——Agent 产出的英文界面也被统一）
  没翻译的：原样保留（安全降级）
```

中英互为 key 是用户提案：不做 en.json / zh.json 两份平行文件，一份字典双向索引，翻译顺序无关、维护单源。

## 语言链与切换

```
?lang=en（URL 参数，测试/旁路实例用）
  > localStorage.agt_lang（浏览器级偏好）
  > navigator.language（浏览器语言）
  > 默认 zh
```

切换即 reload（简单可靠，避免运行时半态）。入口：设置 · 其它页签顶部「界面语言（Language）」下拉（`setLang()`，下拉选中态与当前语言双向同步）。

## 全链路四件

| 件 | 位置 | 说明 |
|---|---|---|
| 引擎 | **src/static/i18n/engine.js（共享单源）**——各页面 `<script src="/i18n/engine.js"></script>` 引入；index.html 内嵌版已移除（第 2 步抽离，8 页零漂移） | `applyI18n()`：TreeWalker 扫文本节点 + title/placeholder/aria-label 属性替换；MutationObserver 监听动态渲染区（150ms 节流）自动翻译；`_t()` 渐进包裹函数（JS 动态拼接串用）；支持 zh / en / bi 三模式 |
| 端点 | src/server.py `GET /api/i18n`（字典）+ `GET /i18n/engine.js`（引擎，第 2 步增） | 双通道均 no-store 直出（改文件即生效，无需重启）；同轮补 `JSONResponse` import |
| 下拉 | index.html `#panel-other` 顶部（钩子区块之前） | 三选：中文 / English / **中文 + English（双语）**；浏览器级偏好持久化，切换即刷新 |
| 字典 | src/static/i18n/dict.json | **759 条 · 已翻 436**（26 条 PoC + 410 条第 2 步批次，高频 UI 全覆盖）；配套清单：`_needs_t.json`（97 条需 `_t()` 包裹的拼接串）+ `_todo.json`（8 页扫描待翻清单，第 2 步驱动） |

## 文案抽取方法论（622 → 349）

run_python 正则扫描 index.html 四类中文文案：

| 类 | 条数 | 去向 |
|---|---|---|
| A · HTML 静态文本 | 159 | 直译进字典 |
| B · 属性（title/placeholder/aria-label/data-label） | 106 | 直译进字典 |
| C · JS 完整字符串（可直译） | 260 | 直译进字典 |
| D · JS 拼接/模板串（需 `_t()` 包裹） | 97 | 不进字典，留 `_needs_t.json` |

二轮精化滤代码噪音（`[);{}=<>\\]|</|hl-|…` 判代码）+ 纯 UI 文案判定 → **349 条可直译骨架**（HTML 126 / 属性 77 / JS 完整串 230）。约 622 条为类间重叠前的毛数。

## PoC 实测（Playwright 旁路实例 `?lang=en`，全绿）

- `ready=true` · 字典 349 条 · 反向索引 26 条
- 「发送」按钮 → **Send**；输入框 placeholder → **"Type a message (Enter to send / …)"**
- `en2zh['Send']` → "发送"（双向互查 ✓）

## 第 2 步：全量翻译 + 8 页铺开 + 引擎共享单源 + bi 双语模式（2026-10-04 · 二，用户提案）

用户一句话：「把其它文字都一次性翻译完，包括 tooltips 以及其它几个页面上的字符」——一次交互四件套：

### 引擎共享单源化：index 内嵌块 → engine.js（8 页一源）

- 引擎抽为独立文件 `src/static/i18n/engine.js`（共享版，头注：字典路径 / 语言链 / 切换即 reload / fallback 原文）
- server.py 新端点 `GET /i18n/engine.js`——引擎直出，与字典端点 `/api/i18n` 双通道 no-store（改文件即生效，无需重启）
- 8 页统一挂载 `<script src="/i18n/engine.js"></script>`（`</body>` 前一行）：index（内嵌版移除）+ agents + memory + rag + stats + wf_monitor + workflow_debug + workflow_editor——单源零漂移，改引擎一处全页生效

### 文案抽取扩到 8 页 + 分批翻译（349 → 759 条）

- 扫描器从 index 单页扩到 8 页：合并去重 **765 条**，其中字典已有 349、**新增待翻 416**（`_todo.json` 清单驱动）
- 分批 LLM 直译（批1 78 条起步，逐批写回 dict.json + 清 _todo）；6 条抽取噪音（拼接/截断串，如 `'+outs[nthIdx].type+'`）不进字典，归 `_t()` 包裹阶段
- 终态：**字典 759 条 · 已翻 436 条**（26 条 PoC + 410 条本轮），高频 UI 文案全覆盖（含 tooltips/placeholder/aria-label）；原骨架 323 条低频条目空值保留待翻

### bi 双语模式：中文主 + 英文副

- 语言枚举 zh / en / **bi** 三态：bi = 中文主文案后跟英文副文案（设置下拉新选项「中文 + English（双语）」，`?lang=bi` 同样生效）
- `i18nInit` 对 bi 照常加载字典建双索引，`documentElement.lang` 保持 `zh-CN`

### bi 实测（9635 旁路 · `?lang=bi`，全绿）

- `ready=true · lang="bi"` · 正向 759 条 · 反向 436 条 · `doc.lang=zh-CN`
- 「发送 Send」按钮 / 输入框 placeholder / 设置下拉标签均双语渲染；`en2zh['Send']` → "发送" 反向命中 ✓
- site-packages 已同步全部产物——9000 实例刷新即见双语；pyproject `package-data` 已覆盖 json，下版 wheel 自动带字典与引擎
