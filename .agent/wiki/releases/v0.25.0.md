## 模型生态四件套（flatkey 接入 → 模型管理 UX 三连）

1. **flatkey provider 预设**：160+ 官方模型网关入库，77 个实测收录（短超时误判补录）、14 个 ⭐ 精选（免费/旗舰/主力轻量）
2. **onboarding 级联**：同 provider 贴一把 key → 当前选中 + 14⭐ 收藏精选自动落库（级联范围收敛为「当前选中 + ⭐ 收藏精选」，不全量 77 张爆炸）
3. **收藏落地 + 搜索摘选弹窗**：预设卡片 ⭐ 一键收藏；「🔍 搜索模型」双分组弹窗——✅ 已配置定位 / 🔌 可一键添加（➕ + ⭐ 徽标）
4. **`/api/models/add-one`**：未配置 preset 条目一键落地，同 provider 已有 key 直接复用（无 key → need_key 转 onboarding 补）

## 多实例组网路由 v2（remote_instance_id）

- 旧路由标记名 `server_id` 极易与工具/MCP 同名参数撞名（remote_* 管理族实证——曾致死循环）→ 改名 `remote_instance_id`
- `_llm_tool_schemas()` 给**每个工具（含 MCP）的 LLM 视图自动注入**该可选参数（deepcopy 不污染 toolbox 原件；remote_* 族豁免防套娃）
- 旧名 `server_id` 仍兼容路由、remote_* 族旧名透明规范化不 TypeError；管理族五件套形参同步改名
