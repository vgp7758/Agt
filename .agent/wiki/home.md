## 快速事实（2026-08 状态）

- 版本 **0.20.1**；`pip install agt-agent`；CLI=`agt`，WebUI=`agt-web`
- 38 个 Python 模块 ~17000 行，零 LangChain 依赖
- 主 Agent id=`_main_`；子 Agent 声明在 `.agent/agents/*.md`（frontmatter DSL）
- 工作流：`.agent/workflows/*.xml|json`，13 类节点，XML 为推荐写作格式
- 工作流 meta 字段：name/description/hook/enabled/hidden/async/auto/coze_url（全链路读写；**hidden 默认 true——未写=不注册 wf_* 工具，显式 hidden="false" 才进工具箱 schema，commit a667da4**）
- 存档：`~/.agt/repos/<repo 目录名>/`（sessions/memories/plans/specs/images/rag；路径由 workspace hash 改为可读转写）
- LLM 调用流水：每 session `llm_calls.jsonl`（含 resp_model/scene/turn·step 轮步标记/usage 归一化）
- 前端气泡：系统自动触发默认折叠，用户指令默认展开，点击切换；聊天面板 user/answer 气泡 hover 浮现复制按钮（innerText 复制，clipboard→execCommand 降级，commit 3a7e9de）
- **过程区折叠降噪（2026-08，commit ee968be）**：💭 思考内容默认折叠——`renderThinking` 流式 chunk 累积进同一折叠组（head 实时字数，**点开全文从不截断**），step/tool_call 事件自动分组、历史渲染同构（s.reasoning/answer_reasoning 走同一函数）；🔧 非 diff 工具默认折叠（diff 类保持展开，result/stream 追进折叠组 body，并行批不追踪归属）+ 钩子行 >140 字折叠——共享 `toggleFold` 基建，后端零改动（详见 [trace-fold](features/trace-fold.md)）
- 运行时状态：POST `/api/status` 返回实例快照（18 顶层字段 + 3 嵌套数组），用于跨实例诊断
- **v0.20.1 发布**（2026-08，commit 327d0a7，PyPI 已上线；汇总自 0.20.0 的 11 笔提交）：①🐞 WebUI 日志面板——LLM 回退/限流/截断实时可见；②中断原因三处留痕——此前后台/子 Agent 异常逃出零原因（本 session 亲历）；③user 事件多端同步（commit 1168ea9）；④`/update-assets`——随包播种资产三方 hash 对比与一键热更新（含 write_text 行尾转换、persona md 漏播种两个暗坑修复）；⑤修复三件——wiki-updater 多实例根因（复活 NameError，commit 6d396af）、detail_base 显式配置不生效（用户报告 /context 恒显 1500）、透明 toast 遮挡输入框（commit 0a415bc）。本 session 从 0.14.1 → 0.20.1 共推 30 个版本（详见 [v0.20.1 发布记录](releases/v0.20.1.md)）
