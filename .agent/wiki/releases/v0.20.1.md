## 可观测性三件套

- **🐞 日志面板**：WebUI 新增日志面板，LLM 调用的回退（fallback 链切换）、限流重试、截断（max_tokens）事件实时可见——此前这些只存在于后端日志，前端无从感知。（2026-08 下旬布局与 spec 抽屉统一：标题栏钉顶 + `logList` 独立滚动，见 [editor-ux 批次十二](../features/editor-ux-improvements.md)）
- **中断原因三处留痕**：后台/子 Agent 任务异常逃出时此前**零原因**（本 session 亲历：任务停了但没有任何提示为什么），v0.20.1 在三处补上中断原因留痕，异常可追溯。
- **user 事件多端同步**：user 事件渲染到同 Agent 的其它客户端/CLI，多端插话实时互见（详见 [user-interaction · 多端消息同步](../features/user-interaction.md)）。

## /update-assets：随包资产热更新

随包播种资产在包升级后与工作区现存版本可能漂移。新增 `/update-assets` 命令做**三方 hash 对比 + 一键热更新**。实现中修掉两个暗坑：`write_text` 行尾转换（写回时行尾被悄悄转换导致 hash 对不上）、persona md 漏播种。

## 修复三件

| 修复 | 现象 | 根因/详见 |
|---|---|---|
| wiki-updater 多实例 | 同名子 Agent 复活后 NameError，产生重复实例 | 复活路径引用未定义名；[multi-agent · 复活路径 NameError](../architecture/multi-agent.md)（commit 6d396af） |

| 透明 toast 遮挡输入框 | toast 透明条悬浮输入框上方，点击输入框失焦 | [user-interaction · 前端 UI 遮罩坑](../features/user-interaction.md)（commit 0a415bc） |
