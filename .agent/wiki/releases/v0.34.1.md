## 启动性能根治：Session.load 188s → 2.8s（本版核心之一）

超大主线 session（数千轮量级）load 长达 188s，启动被整体阻塞。两刀合围：

- **收敛期 0 渲染**——load 重放/收敛阶段不做中间渲染，收敛完成一次性呈现
- **sos 预检**——预检判定「注定无效」的 LLM 浓缩直接跳过，不再白烧调用

实测 **188s → 2.8s**（约 67 倍）。

## 更新方式

```bash
pip install -U agt-agent==0.34.1
```

已装实例 `/restart` 后全部生效。**多实例部署务必同步升级**（如 20048）——toollog 落盘路径已迁移到 repo 共享单文件，旧代码按 per-session 路径找不到新文件；升级后旧 per-session toollog 会在 load 时自动并入共享文件，**无需手动迁移**。
