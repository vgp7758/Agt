# v0.33.0 发布记录

**发布细节**：

- **先收编再打版**：pv-producer 的 yml 自改单独 commit（`85ecf45`）进主干，随后版本 commit（`371b18b`，1 file changed = paths.py）——子 Agent 自治改动与版本工程分离。
- **网络对照**：v0.30.1 轮 upload.pypi.org TLS 间歇阻断需后台自动重试服务（见 [ops · PyPI TLS 阻断](../guides/ops.md)）；本轮全程顺畅一次成——「间歇性」结论再次验证，重试服务留作兜底。

| 4 | 🖼 **上下文工程** | 生成图自动可视（工具产物新增图伪造 read_file 对注入投影，视觉 Agent 省一次真实读图）；before_turn 检索钩子只服务人类直输轮（后台来源短路） | [image-autoview](../features/image-autoview.md) · [workflow-hooks · 来源短路](../architecture/workflow-hooks.md) |
