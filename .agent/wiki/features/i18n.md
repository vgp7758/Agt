# WebUI 界面国际化（i18n） · 中英双向字典引擎（2026-10-04，用户提案，commit 9a982e7）

## 职责

WebUI（src/static/index.html）全界面中英双语：静态文案运行时替换、动态渲染区自动跟随、语言偏好浏览器级记忆。第一版只覆盖 WebUI；字典渐进补齐，**缺翻译自动 fallback 原文**（双语混排过渡期页面不残缺）。

## 双向字典设计（用户提案的核心巧思）

```
字典一份：src/static/i18n/dict.json   { "中文原文": "English text" }
引擎加载时建双索引：zh2en + en2zh（同一文件两个方向都能查）
  en 模式：界面里的中文原文 → 替换英文
  zh 模式：界面里的英文原文 → 替换回中文（Agent 双语环境下写代码，
           UI 文案写哪侧都能被归一——Agent 产出的英文界面也被统一）
  没翻译的：原样保留（安全降级）
```

中英互为 key 是用户提案：不做 en.json / zh.json 两份平行文件，一份字典双向索引，翻译顺序无关、维护单源。

## 语言链与切换

```
?lang=en（URL 参数，测试/旁路实例用）
  > localStorage.agt_lang（浏览器级偏好）
  > navigator.language（浏览器语言）
  > 默认 zh
```

切换即 reload（简单可靠，避免运行时半态）。入口：设置 · 其它页签顶部「界面语言（Language）」下拉（`setLang()`，下拉选中态与当前语言双向同步）。

## 文案抽取方法论（622 → 349）

run_python 正则扫描 index.html 四类中文文案：

| 类 | 条数 | 去向 |
|---|---|---|
| A · HTML 静态文本 | 159 | 直译进字典 |
| B · 属性（title/placeholder/aria-label/data-label） | 106 | 直译进字典 |
| C · JS 完整字符串（可直译） | 260 | 直译进字典 |
| D · JS 拼接/模板串（需 `_t()` 包裹） | 97 | 不进字典，留 `_needs_t.json` |

二轮精化滤代码噪音（`[);{}=<>\\]|</|hl-|…` 判代码）+ 纯 UI 文案判定 → **349 条可直译骨架**（HTML 126 / 属性 77 / JS 完整串 230）。约 622 条为类间重叠前的毛数。

## 修复轮三连：看板闪烁 / fabDock·顶栏按钮 / tooltips 全中文（2026-10-04 · 三，用户实锤，commit 6d95611）

用户三点反馈：①团队看板 UI 在中英文来回切；②消息框上方按钮里的文字只有中文；③所有 tooltips 里也只有中文。一次交互三层修复（commit `6d95611`，site-packages 已同步，刷新即见）：

### 闪烁根因：150ms 防抖窗 → 0ms 立即翻译

- 团队看板每 3s 自动重渲染，MutationObserver 的 150ms 节流窗意味着**每次重渲染都先闪一帧中文**再被翻成双语——用户看到的「中英文来回切」就是这个中文中间态
- 修复：防抖窗归零（`setTimeout(…, 0)`）——重渲染批次内同步完成翻译，中文中间态窗口消失；批次合并不受影响（同一 tick 内多次变更仍只翻一次）

### observer 增 attributes 监听：动态 `el.title` 设置不再漏翻

- 原 observer 只监听 `childList`（文本节点增删）——**渲染函数事后 `el.title='中文'` 的动态属性设置不触发任何事件**，这是 tooltips 全中文的结构性根因（第 2 步字典里明明有翻译，却没机会被应用）
- 修复：监听加 `attributes: true`（title / placeholder / aria-label / data-label 四属性），动态设置即时翻译

### 补批 55 条：fabDock data-label + 顶栏按钮 + 动态 tooltips

- fabDock 图标 hover 标签（施工方案 Specs / 日志 Logs / 团队看板 Team board / 工作流编辑器 Workflow editor / 长期记忆 Long-term memory…）
- 顶栏按钮（⏸ 挂起 / ⏹ 停止 / ☆ 收藏 / 🔧 工具 / 💻 终端执行 / 📁 加图 / 清空 Clear / 🔄 重连 / 连接 Connect…）
- 动态 tooltips（复制气泡 / 追加输入框 / 收藏轮 / 折叠展开 / 切换模型 / 设置弹窗各键长描述）
- 字典 **765 条 · 已翻 491**（此前 759 · 436）；实测 9000 实例 bi 模式：tooltip 已双语渲染（「复制整个气泡内容到剪贴板 Copy entire bubble to clipboard」），纯中文 tooltip 仅剩 1 条

### 已知留白：模型卡片 tooltip（preset 数据侧）留待 `_t()` 化
